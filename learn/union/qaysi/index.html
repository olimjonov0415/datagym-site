#"Hammasi" turidagi savollar

Barcha majburiy kurslarni o'qiyotgan talabalar kerak. Subquery darsida bu ikki marta NOT EXISTS bilan yechilgan edi. EXCEPT bilan o'qish osonroq: majburiy kurslardan talabaning kurslarini ayirasiz, hech narsa qolmasa, talaba hammasini o'qiyapti.

Shu usul bilan ikki to'plamning tengligini tekshirish mumkin: A dan B ni ayirsangiz bo'sh, B dan A ni ayirsangiz ham bo'sh. Kurslari aynan bir xil talabalar juftligi:

#JOIN, EXISTS yoki to'plam amali

Ko'p savolni ikki xil yechsa bo'ladi. Qachon qaysi biri?

To'plam amallari butun qatorni solishtiradi. Bu ham kuchi, ham cheklovi. Do'konda ham sotilgan onlayn savdolar kerak, id si bilan. INTERSECT ga id ni qo'shsangiz, u ham solishtiriladi:

Natija ma'nosiz: 1-savdo ikkala jadvalda choynak, 5-savdo ikkalasida futbolka bo'lgani uchun chiqdi, 2-choynak va kitob esa yo'q. Bitta jadvaldan ustunlar kerak bo'lsa, ikkinchisi faqat tekshiruv uchun ishlatilsa, EXISTS to'g'ri yo'l:

Taxminiy qoida:

  • ikki natija bir xil ko'rinishda va qatorni butunligicha solishtirish kerak (ayniqsa NULL lar bilan): INTERSECT, EXCEPT;
  • natijada bir jadvalning ustunlari, ikkinchisi faqat shart uchun: EXISTS, NOT EXISTS;
  • ikkala jadvaldan ham ustunlar yonma-yon kerak: JOIN;
  • har xil manbadagi qatorlarni bitta ro'yxatga yig'ish: UNION ALL, takrorlar ataylab olib tashlansa UNION.

#Qisqacha

Nima kerak Qanday yoziladi
Ikki natija, takrorsiz SELECT ... UNION SELECT ...
Ikki natija, hamma qator SELECT ... UNION ALL SELECT ...
Qator qayerdan kelgani SELECT 'onlayn' AS source, ...
Ikkalasida ham bor SELECT ... INTERSECT SELECT ...
Birida bor, ikkinchisida yo'q SELECT ... EXCEPT SELECT ... (tartib muhim)
Ustun nomlari birinchi so'rovdan; ustunlar o'rni bo'yicha ulanadi
Saralash oxirida, natija ustuni nomi yoki raqami: ORDER BY 2
Har qismda alohida LIMIT SELECT * FROM (... LIMIT 1) a UNION ALL SELECT * FROM (...) b
Guruhlash, jami qatori SELECT ... FROM (... UNION ALL ...) t GROUP BY ...
NULL lar to'plam amallarida teng; EXCEPT da NOT IN tuzog'i yo'q
Takrorlar soni bilan PostgreSQL: EXCEPT ALL, INTERSECT ALL; SQLite: ROW_NUMBER + EXCEPT
INTERSECT boshqa amal bilan PostgreSQL'da oldin bajariladi; hosila jadval bilan tartibni aniq ko'rsating
Faqat bir tomonda (A EXCEPT B) UNION (B EXCEPT A), har qism hosila jadvalda
