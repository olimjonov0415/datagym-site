#Bo'shliqning ko'rinishlari

Telefon raqami yo'q mijozlar nechta? clients jadvalida raqam yo'qligi uch xil yozilgan: Nodirada NULL, Bekzodda bo'sh satr '', Dilnozada uchta probel. COUNT(phone) faqat NULL ni chiqarib tashlaydi:

Yetti mijozdan oltitasida "raqam bor", haqiqatda esa to'rttasida. Farqni ikki funksiya yopdi: TRIM probellarni olib tashladi va Dilnozaning ' ' i bo'sh satrga aylandi, NULLIF(x, '') esa bo'sh satrni NULL qildi. Shundan keyin raqami yo'q hamma qator bir xil ko'rinishda.

Bo'sh satr NULL emas

phone IS NULL bo'sh satrni topmaydi, phone = '' esa NULL ni topmaydi. Ikkalasini ham bitta shartda tekshirishning eng qisqa yo'li: NULLIF(TRIM(phone), '') IS NULL.
