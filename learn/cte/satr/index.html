#Satrni harfma-harf yurish

Rekursiya satr ustida ham ishlaydi: har qadamda bitta harf yoki bitta bo'lak olinadi. So'zni teskari yozish (SQLite'da buning uchun tayyor funksiya yo'q):

Har qadamda pos bittaga kamayadi va o'sha joydagi harf acc ga qo'shiladi. Oxirgi qatorda (pos = 0) tayyor natija: molas. Xuddi shu usulda vergul bilan yozilgan ro'yxatni bo'laklarga ajratish mumkin: har qadamda birinchi vergulgacha bo'lgan qism olinadi, qolgani keyingi qadamga o'tadi. Vergulning o'rnini SQLite'da INSTR(satr, ','), PostgreSQL'da STRPOS(satr, ',') topadi.

#Dialektlar farqi

Rekursiv CTE'da PostgreSQL SQLite'dan ancha qattiqqo'l. Uchta farq ko'p uchraydi.

Birinchisi: RECURSIVE so'zi. SQLite usiz ham rekursiyani tushunadi, PostgreSQL esa CTE o'zini o'zi ishlatganini ko'rib, bunday jadval yo'q deydi:

Ikkinchisi: ustun turlari. PostgreSQL ustun turini boshlang'ich qismdan oladi va rekursiv qism boshqa tur bersa, xato beradi. Bu yerda boshlang'ich qismda oddiy INTEGER, rekursiv qismda esa BIGINT:

Uchinchisi: sonning sig'imi. PostgreSQL'da INTEGER 2 147 483 647 dan oshmaydi, 13! esa 6 227 020 800. SQLite'da butun son 64 bitli, 20! gacha bemalol sig'adi:

Ikkala holatning ham davosi bitta: boshlang'ich qismdayoq kerakli turni bering, masalan SELECT 1, CAST(1 AS BIGINT). Shunda hisob boshidan oxirigacha BIGINT da boradi va so'rov ikkala bazada ham bir xil ishlaydi.

#Qisqacha

Nima kerak Qanday yoziladi
Subquery'ga nom berish WITH t AS (SELECT ...) SELECT ... FROM t
Bir nechta bosqich WITH a AS (...), b AS (SELECT ... FROM a) SELECT ...
Rekursiya WITH RECURSIVE r(ustunlar) AS (boshlanish UNION ALL rekursiv qism)
To'xtash rekursiv qismda WHERE n < 10 yoki daraxtning tugashi
Sonlar yoki oylar qatori SELECT 1 UNION ALL SELECT n + 1 FROM r WHERE n < 12
Bo'sh oylar 0 bilan qator + LEFT JOIN + COALESCE(SUM(...), 0)
Daraxt bo'ylab pastga boshlanish: ildiz, rekursiv qism: JOIN ... ON e.manager_id = t.id
Takrorlar haqiqiy ma'lumot UNION ALL
Halqali graf UNION + chegara yoki yo'lni satrda saqlash
Katta sonlar boshlang'ich qismda CAST(1 AS BIGINT)
