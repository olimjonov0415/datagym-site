#So'rov qanday tartibda bajariladi

SELECT so'rovning boshida yoziladi, lekin birinchi bo'lib bajarilmaydi. Baza so'rovni taxminan mana bu tartibda ishlaydi:

  1. FROM: qaysi jadvaldan;
  2. WHERE: qaysi qatorlar qoladi;
  3. SELECT: ustun va ifodalar hisoblanadi, AS dagi nomlar shu yerda paydo bo'ladi;
  4. DISTINCT: takrorlar olib tashlanadi;
  5. ORDER BY: saralanadi;
  6. LIMIT va OFFSET: kerakli bo'lagi kesib olinadi.
