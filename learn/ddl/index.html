#Jadval yaratish

CREATE TABLE dan keyin jadval nomi, qavs ichida vergul bilan ustunlar: har biri nomi va turi bilan.

Bu misolda jadval yaratildi, uchta qator qo'shildi va o'qildi. CREATE TABLE o'zi hech narsa qaytarmaydi.

Jadval bir marta yaratiladi. Bor nom bilan ikkinchi marta yaratsangiz, xato chiqadi:

Skriptlarda ko'pincha CREATE TABLE IF NOT EXISTS yoziladi: jadval bor bo'lsa, buyruq jim o'tib ketadi. Lekin u bor jadvalning tuzilishini tekshirmaydi, ustunlari boshqacha bo'lsa ham indamaydi. Jadvalni o'chirish DROP TABLE cities, u ma'lumot bilan birga ketadi.

#Ustun turlari

Ko'p ishlatiladiganlari: INTEGER (butun son), TEXT (matn), DATE (sana), NUMERIC(10, 2) (aniq kasr son, masalan pul). PostgreSQL turni qat'iy tekshiradi. SQLite'da esa tur faqat tavsiya:

Dialektlar farqi

PostgreSQL 'o''n besh' ni butun songa aylantira olmaydi va qatorni rad etadi. SQLite avval aylantirib ko'radi ('15' 15 bo'lardi), bo'lmasa matnning o'zini saqlaydi. qty ustunida endi matn turibdi, SUM(qty) uni jim 0 deb hisoblaydi.

Matn uzunligi ham shunday:

PostgreSQL 9 belgili matnni VARCHAR(5) ga sig'dirmaydi. SQLite qavsdagi sonni umuman o'qimaydi. Uzunlik ikkala bazada tekshirilishi kerak bo'lsa, CHECK (LENGTH(code) <= 5) yozing, bu haqda uchinchi qadamda.

#CREATE TABLE ... AS

Jadvalni so'rov natijasidan ham yaratish mumkin. Ustunlar so'rovdan, qatorlar natijadan olinadi. Shaharlar bo'yicha hisobot:

Ikkita shahar. Mehmon buyurtmasi va yo'q 9-mijozning buyurtmasi JOIN dan o'tmadi, Bekzodning buyurtmasi yo'q. Hisobot yaratilgandan keyin Malika yana buyurtma berdi, lekin Samarqand qatorida baribir bitta buyurtma. city_stats yaratilgan paytdagi suratni saqlaydi, orders bilan boshqa bog'lanmaydi. Har doim joriy holat kerak bo'lsa, jadval emas, CREATE VIEW yoziladi.

AS bilan yaratilgan jadval cheklovlarni ko'chirmaydi:

customers da id birlamchi kalit, name majburiy. Nusxada ikkalasi ham yo'q: ikkinchi 1-raqam ismsiz qo'shildi. Faqat tuzilish kerak bo'lsa, WHERE 1 = 0 qo'shiladi va jadval bo'sh yaratiladi.

Mijozlar bo'yicha hisobot jadvali customer_totals ni yarating: name (mijoz ismi) va orders_count (uning buyurtmalari soni). Faqat customers da bor va buyurtmasi bor mijozlar kirsin. Keyin SELECT name, orders_count FROM customer_totals ORDER BY name bilan uni chiqaring.
