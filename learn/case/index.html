#Qidiruvli CASE

CASE har bir qator uchun shartlarni yuqoridan pastga tekshiradi va birinchi rost chiqqan shartning qiymatini qaytaradi. Talabalarga baho beramiz:

Dilnoza va Sardor imtihonga kelmagan, lekin ular ham qoniqarsiz oldi. Sababi oddiy: NULL >= 86 rost emas, qolgan shartlar ham, va qator to'g'ri ELSE ga tushdi.

NULL ELSE'ga tushadi

NULL bilan har qanday solishtirish rost bo'lmaydi. Ustunda NULL bo'lishi mumkin bo'lsa, CASE uni o'zi ajratmaydi, ELSE bor bo'lsa, unga yuboradi. NULL uchun alohida shartni boshida yozing.

#Birinchi mos kelgan shart

Ikkinchi shartda score < 86 yozilmagani bejiz emas. 86 va undan yuqorisi birinchi shartda to'xtab bo'lgan, ikkinchisiga yetib kelmaydi. Lekin bu qulaylikning teskari tomoni ham bor: shartlar tartibi natijani o'zgartiradi. Pastdan yuqoriga yozib ko'ramiz:

Aziz 92 ball bilan qoniqarli oldi: 92 birinchi shartga ham mos keladi, CASE shu yerda to'xtadi. yaxshi va a'lo shartlariga umuman navbat kelmaydi. Shartlarni "pastki chegara" bilan yozsangiz, eng kattasidan boshlang. Pastdan boshlamoqchi bo'lsangiz, < bilan yozing: WHEN score < 56, keyin WHEN score < 71 va hokazo.

#ELSE yozilmasa

Hech bir shart rost chiqmasa va ELSE yo'q bo'lsa, CASE NULL qaytaradi. Xato chiqmaydi, shuning uchun buni sezmay qolish oson:

Ba'zan aynan shu kerak bo'ladi, masalan, keyinroq agregatlar ichida. Lekin ustunda "qolganlar" uchun ham qiymat bo'lishi kerak bo'lsa, ELSE ni unutmang.

#Oddiy CASE

Bitta ustun bir nechta aniq qiymat bilan solishtirilayotgan bo'lsa, qisqaroq yozuv bor. Ustun CASE dan keyin bir marta yoziladi, WHEN larda esa faqat qiymatlar. Buyurtma holatlarini inglizchaga o'giramiz:

Bu CASE WHEN status = 'yangi' THEN ... ning qisqa shakli. Natija bir xil, faqat o'qish osonroq. Holati NULL bo'lgan 7-buyurtma ELSE ga tushdi.

#WHEN NULL ishlamaydi

Oddiy CASE ning har bir WHEN i aslida = bilan solishtiradi. NULL ni ham shunday ushlab ko'ring. Kelmagan talabalar nechta chiqadi?

Hech kim. CASE score WHEN NULL bu score = NULL degani, NULL bilan = esa hech qachon rost emas, hatto NULL = NULL ham. Dilnoza va Sardor ELSE ga tushib, keldi bo'ldi. NULL ni tekshirish uchun qidiruvli CASE va IS NULL kerak:

CASE x WHEN NULL

Bu xato hech qanday xabar bermaydi, so'rov shunchaki noto'g'ri natija qaytaradi. Ustunda NULL bo'lishi mumkin bo'lsa, oddiy CASE o'rniga CASE WHEN x IS NULL THEN ... WHEN x = 'a' THEN ... yozing.

#Natija turi bitta

CASE ning hamma tarmog'i bitta turdagi qiymat qaytarishi kerak. Kelmaganlar uchun ball o'rniga so'z yozmoqchi bo'lsangiz:

Dialektlar farqi

SQLite ustunda har xil turdagi qiymatlarni bemalol aralashtiradi: Azizda son, Dilnozada matn. PostgreSQL esa CASE ning natija turini tarmoqlardan aniqlaydi (bu yerda score tufayli butun son) va 'kelmagan' ni songa aylantira olmay xato beradi. Ikkala bazada ishlashi uchun sonni matnga aylantiring: ELSE CAST(score AS TEXT).
